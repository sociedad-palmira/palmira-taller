# Palmira · Taller

App del taller de Palmira Diseño & Mueblería para la escuadradora:

- Dimensionado de tableros (con veta, refilado y sobrantes) a partir del archivo que exporta el plugin de SketchUp, o de trabajos ingresados a mano.
- Etiquetas de 60 × 40 mm para cada pieza (medidas, tapacanto y QR que muestra el mueble en 3D), impresas en una Xprinter por Bluetooth o USB.
- Orden de corte, inventario de sobrantes y de tapacanto, y trabajos de servicio de corte y enchape.

La app es una sola página (`index.html`). Los datos de trabajos e inventario se guardan en cada equipo, no en este repositorio.

Página: https://sociedad-palmira.github.io/palmira-taller/
